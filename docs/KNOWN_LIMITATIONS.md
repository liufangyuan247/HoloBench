# Known limitations

- M0 contains no optical solver and produces no physical prediction.
- The app currently requires an OpenGL 4.6 core context; macOS is unsupported.
- Only a Windows Clang/Ninja development environment has been selected for the first local verification pass.
- Compute backend interfaces are placeholders.
- JSON project format v1 is intentionally minimal and has no migration framework yet.
- There is no undo/redo, autosave, crash recovery, localization, accessibility layer, or Steam integration.
- Hardware control and digital-twin calibration are long-term modules, not M0 capabilities.

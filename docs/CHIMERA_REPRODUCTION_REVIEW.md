# 面向 CHIMERA 复现的项目评审与改进建议

日期：2026-09-05。审阅基线：`a3b25b7`。

用户补充的核心交互：黑背景、白光/单色照明、拖动已记录干板直接观察重建像，允许渐进渲染。该要求纳入 P2–P4 验收，详见 [全息干板交互式重建展示间](HOLOGRAM_SHOWROOM_DESIGN.md)。

本次是源码与项目文档评审，没有运行交互界面、重新构建或复测物理模型。下文区分已确认的代码行为、由代码推导的问题与待实施方案；不把已有测试数量当作实验复现的证据。本文是建议，不改变既有里程碑状态。

## 1. 目标需要收敛到可学习搭建的打印实验

用户目标是学习光路搭建，并最终实现自己的全彩反射全息照相及 CHIMERA 系统。当前 M9 的目标明确是标量、近轴范围内的 CHIMERA-like 虚拟打印机，且明确排除了专有光学处方复现。M9 软件验收通过与达到上述实验目标是不同的验收范围。

目前尚无用户指定的论文、光路图、器件表或性能指标。因此先以“全彩反射式 hogel 全息立体图打印系统”为工作目标；具体 CHIMERA 拓扑、脉冲/连续光源、调制器类型、视场和材料必须在选定参考资料后确定，不能把现有 X-cube 加共用 SLM 的布局当作目标设备事实。

直接拍摄实物的反射全息照相与从多视图数据逐点打印 hogel，需要不同的物光产生方式。前者可作为学习干涉、曝光和布拉格重建的入门实验；面向打印机的主线应尽快进入 SLM 调制、角度编码、打印头和平台扫描。复杂实物散射、任意实验器件库扩展暂不优先。

建议下一次产品验收只要求一个完整实验：用户在共享 3D Bench 中对准单色单 hogel 打印光路，测得物光/参考光的功率与重叠，完成曝光，关闭记录照明，用独立重建照明观察结果；刻意调错一个器件时，模拟器能说明失败原因，重建也确实随之改变。

## 2. 已确认的问题及证据

### 界面：操作区正在挤占实验本身

- `app/Application.cpp:11191` 在绘制视口之前依次绘制器件、光源、对准、光场、曝光和 CHIMERA 操作条，之后才计算视口剩余尺寸。
- 器件栏固定高 164 像素（6493），CHIMERA 栏固定高 218 像素（7308）。两者在 CHIMERA 工作台就占 382 像素，尚未计间距和按选择出现的操作条。各上下文条并非始终同时显示。
- 默认停靠继续预留右侧 Inspector、底部 Validation/参考分析窗口（11135 附近）；Inspector 在沙盒内容后继续绘制 Legacy Reference Workbenches（12341 附近）。

这不是单纯的配色问题，而是开发工具、实验操作和学习入口没有分清主次。

### 机械：现在保证了单个模型有效，还没有保证整台仪器可装配

- `app/ChimeraRecipe.cpp` 的 `component`/`addGenerated` 直接放置光学坐标，不附加机械装配；默认器件的 `mechanicalAssembly` 为空（`optics/scene/BenchScene.cpp:565` 附近）。
- 自动布局把光轴放在 `Y=0`，同时渲染桌面网格也是 `Y=0`（`render/OpticalBenchRenderer.cpp:559` 附近）。无机械装配时，`addPostAndBase` 从器件中心向局部负 Y 添加支柱与底座（`render/ProceduralInstrumentGeometry.cpp:378`）。由此可直接推导：自动布局的支撑几何落在桌面网格以下；不能只靠调相机修正。
- PCG 测试覆盖有限顶点、尺寸、姿态、确定性等，但所审阅的布局生成器和几何测试没有整台 Bench 的机械间隙与干涉验收。
- SLM 用实心背板建模（`render/ProceduralInstrumentGeometry.cpp` 的 `SpatialLightModulator` 分支），自动光路却沿其法线穿过。需要明确这是透射式调制器还是反射式 SLM，并统一外观、端口和光路。若目标是反射式 LCOS，还需真实的入射/出射分离设计。
- `DynamicBenchTracer` 主要寻找器件光学代理面与有效区域，不消费支柱、底座、背板的阻挡实体。渲染实体与光学真值独立是正确架构，但缺少显式机械遮挡代理时，会允许视觉上的“穿壳光路”。

尚未实测用户所见的所有器件间穿插对。后续应对当前保存的 Bench 和三种自动合光方案输出逐对干涉报告，再区分装配接触、真实碰撞、透明渲染与诊断线叠加。

### 光学：打印头与重建链仍有明显简化

1. **“4f 中继”的名字超出了生成布局。** `app/ChimeraRecipe.cpp:690` 只生成一片 `IdealThinLens`，SLM 到该透镜距离为 f，另有固定比例放置的 stop。单透镜可以承担傅里叶映射，但不是标准双透镜 4f 成像中继。必须分别定义 SLM 面、傅里叶面、孔径面和 hogel 面，说明每一对面的共轭关系。
2. **合光共轴并不意味着全系统消色差。** X-cube 的理想端口模型可以验证几何合光；它不能证明中继像差、SLM 波长响应、材料布拉格选择性和 RGB 重建配准正确。`CascadedDichroic` 生成的两个 splitter 当前默认都是 R=T=0.5，生成时未绑定光谱镀膜数据（同文件 550 附近），不能当作已实现波长选择性的真实二向色镜。
3. **方向重建仍依赖输入答案。** `app/ChimeraReconstruction.cpp:243` 附近把 `sample.linearRgb` 分别乘 RGB 通道的 `nominalReplay.kogelnik.diffractionEfficiency` 得到重建强度；角度则来自 SLM 位置和 recipe 焦距。`ChimeraBenchWorkflow.cpp:113` 在产品路径中调用该方法。它有用途，是理想角度/颜色预览；但不是从记录介质状态独立求出的完整重建。
4. **相机改进不能补上前级缺失。** 当前相机路径确实使用了放置的真实镜片处方和有限瞳孔传播；输入仍来自上述方向样本。必须保留这部分工作，同时补足打印头到记录介质再到出射场之间的因果关系。
5. **反射体全息模型范围有限。** `optics/holography/BenchVolumeHologram.cpp` 从两束中心方向构造光栅矢量，再换算成等效对称布拉格角调用 Kogelnik 模型，并可附带采样物光/参考光场。它为局部近似提供基础，不等于完整角度复用的体光栅响应。非对称倾斜、偏振、材料动态范围及多重曝光相互作用需要单独验证。
6. **近轴门槛不一致。** CHIMERA 生成器的 `scalar_paraxial_na` 到 NA>0.5 才给警告（`ChimeraRecipe.cpp:371` 附近），而其他近轴模型文档使用约 0.1 的小参数检查。门槛应来自实际启用模型的误差验证，不能用一个宽松的通用阈值替代。

## 3. 界面方案：一张桌子、一项当前任务、一个测量结果

主窗口建议由顶部紧凑流程条、大面积 3D Bench、按需右侧抽屉组成。流程为“搭建 → 对准 → 曝光 → 重建”，每一步操纵同一个 Bench。流程导航不能绕过真实器件或偷偷切换固定光路。

- 默认收起器件库，点击“添加器件”或快捷键后打开可搜索抽屉，拖放到桌面；保留空 Bench 和可编辑完整参考 Bench 两个入口。
- 点选器件只显示其当前操作：移动、俯仰、偏航、相关旋钮和少量常用读数。SI 精确输入、校准文件、求解器参数放“高级”。
- 测量窗口依附放置的 Screen/Probe/功率计。默认只显示光斑与功率，按需切换强度、相位、光束剖面、角谱；可锁定显示范围比较调整前后，避免自动归一化掩盖功率损失。
- 3D 视图提供实体、光路、光学剖面三种显示组合；清晰区分波长与物光/参考光分支，支持只看所选光路。空气中的光线是解释性叠加，不冒充肉眼可见的电磁场。
- 故障提示指出器件和可操作原因，例如“第二个光阑截掉 35% 物光”“板上两束光中心相距 0.8 mm”；给出下一项测量，不直接替用户隐藏修正。
- 旧数值参考窗口集中到“分析工具”，默认不占新手布局。

建议 UI 验收在 1366×768 与 1920×1080 下分别检查：默认实验视口至少占可用内容面积的 65%；无需滚过参数表就能完成一次调镜、观察光斑和曝光；保存再开仍回到原实验与当前步骤。这些是拟议产品指标，尚未测量。

## 4. 机械方案：统一参数，分别生成外观、装配包络与光学代理

保留 PCG，不优先购买一套互不相干的精细模型。每个仪器规格应产生：

| 输出 | 职责 |
| --- | --- |
| 装配坐标与连接点 | 底座固定于桌面，支柱高度和转台位置确定光学坐标；定义可调范围 |
| 机械实体与运动包络 | 有向盒、圆柱等解析形体，判断碰撞、旋钮空间和平台全行程可达性 |
| 遮挡代理 | 不透明实体、通光孔与吸收表面，参与光线阻挡和局部光场裁剪 |
| 光学表面与端口 | 决定反射/透射、材料与口径，是求解器真值 |
| 可丢弃显示网格 | 从相同规格生成外观，不反向定义以上任何物理属性 |

生成器先解决光学约束，再布置支架和折叠光路，最后做碰撞及通光检查；不能靠任意挪动物镜或光阑来消除穿模而破坏共轭关系。碰撞先用 AABB 粗筛，再用有向盒/解析实体复核，孔洞与合法装配接触必须明确建模。

默认光轴高度应作为桌面以上的机械参数统一设置，例如先采用 100 mm 的可配置名义值；这不是目标设备测量值。所有扫描位置都要检查，而不只检查中心 hogel。新增格式需严格迁移旧 Bench，不能移动旧项目中的光学元件而不说明。

## 5. 光学方案：优先补齐决定打印成败的模型

基础架构继续使用全局几何光线和局部二维复场。全房间三维波动网格不适合此目标。

### 5.1 先建立可信打印头

根据目标资料明确单波长链：激光 → 快门/功率控制 → 空间滤波与扩束 → 分光；物光经过目标类型的 SLM、所需中继与打印物镜到板上；参考光经过功率与偏振控制、扩束和折叠镜到板另一侧。并非每种真实 CHIMERA 架构都使用同一拓扑。

需测量和显示 SLM 有效照明面积、板上 hogel 尺寸、角分布、各面口径截光、两臂光程差、功率比和干涉可见度。对于连续窄线宽光源重点检查相干长度和漂移；若参考设备采用脉冲曝光，还需脉冲能量、同步及时间重叠，不能只用稳态功率乘任意曝光时间代替。

如果确实采用双透镜 4f 中继，用 f1、f2、放大率及共轭面推导布局，并用成像倒置/缩放和傅里叶面位置的独立基准验证。打印物镜的角度映射与视场再单独验证；真实镜片处方已有基础，应从低 NA 有界模型接入，再根据目标视场决定是否需要宽角度/矢量扩展。

### 5.2 使重建摆脱原始图像数据

建立独立的记录产物：保存记录几何、曝光与材料状态、波长通道、求解所需的局部光栅/复响应及近似标签。具体采用局部光栅集合、角谱耦合还是更高阶模型，应在 ADR 中界定有效域和 CPU 基准，不直接承诺一个完整 Maxwell 求解器。

重建接口只依赖记录产物、重建照明、当前观察光学和材料/校准数据。原始多视图和 SLM 指令可以供诊断比较，但不得提供重建颜色或方向的答案。先证明单 hogel 的闭环，再讨论多 hogel 相干拼接。

当前方向预览保留为快速预览/解析参考，并在产品中明确标识。独立重建应能在移除原始视图文件之后工作。

### 5.3 增加与实验判断直接相关的真实性

- 两臂先加入可验证的 Jones 偏振和标量互相干描述，验证正交偏振抑制、光程差及振动平均对条纹可见度的影响；沿折叠光路维护一致坐标基。
- RGB 镀膜、SLM 响应和透镜色差逐波长计算；共轴只是起点。记录和显示保持不同波长不互相干。
- 材料响应连接曝光剂量、折射率调制、厚度与收缩；已有校准资产机制可以复用。多重曝光竞争和动态范围若未建模，应明确限制，不能假设三个通道永不相互影响材料。
- 重建照明加入有限谱宽和角分布，做布拉格波长/角度扫描；颜色显示需要光谱响应与色度处理。三条 RGB 激光重建不足以证明白光观看效果。
- 光场预览可用渐进采样，但用于曝光与验收的采样必须满足目标带宽并有收敛证据；512/1024 网格本身不是“真实”的保证。

## 6. 建议实施顺序与退出条件

| 顺序 | 交付 | 必须看到的证据 |
| --- | --- | --- |
| P0：明确参考系统 | 参考资料、拓扑、器件类型、SLM/波长/材料/视场/hogel/激光时序规格表；缺项标未知 | 每个实物结论有出处，假设可追溯；不把专有处方当已知 |
| P1：可操作的单色台架 | 简化主界面、统一机械高度、碰撞/通光检查、按约束生成打印头 | 3D 中可搭建与对准；参考 Bench 无未解释干涉；遮住任一记录臂会阻止正常记录 |
| P2：单 hogel 独立记录与重建 | 记录产物及独立 replay 接口，复用已有场传播/相机 | 删除源视图仍可重建；改变 SLM、移焦或截光会改变记录和重建；移动观察器只影响观察 |
| P3：RGB 反射打印 | 逐色对准、响应和剂量；有限谱宽重建 | 颜色通道配准、布拉格扫描和曝光变化与独立基准一致；超出材料域明确拒绝 |
| P4：扫描与多视图 | 从 2×2、8×8 小区块到较大打印区域；平移台、曝光队列和断点续打 | 相邻 hogel 拼接、视差方向、串扰、平台运动及保存恢复有证据 |
| P5：实测校准 | 实测 SLM LUT、光斑、功率、材料曲线及机械误差 | 同一台架/同一测量条件下给出模拟与实测残差，随后才谈硬件预测能力 |

P1 和 P2 优先于更多器件外观、更多预设或扩大整版分辨率。M9 的批处理、数据哈希、恢复和相机可以复用；核心 FFT、几何追迹、校准资产和项目存储不需要推倒重写。

## 7. 应新增的实验验收，而不只是实现一致性测试

1. 两孔对准：在 3D 中调镜穿过两个分离光阑；错调后探测面偏移与反射定律一致。
2. 中继与角度编码：独立 ABCD/傅里叶参考检验共轭面、倍率、方向符号和实际角度分布，包含离轴及口径边缘样本。
3. 干涉：功率比 r 的理想可见度为 `2*sqrt(r)/(1+r)`；同功率正交偏振应无干涉项；相干长度/时序条件外可见度下降。
4. 反射光栅：单平面波对检验光栅矢量、布拉格峰和角度/波长带宽；等效对称模型只在已验证域作为参考。
5. 因果扰动：重拍前移动 SLM、透镜、孔径、参考镜，分别验证图案、焦点、功率与布拉格响应；不得仍输出理想输入答案。
6. 记录冻结：曝光后移除或关闭记录设备，保留记录产物；修改观察相机不应使已记录介质失效。需要区分记录版本与观察版本，避免当前全 Bench revision 过期机制妨碍真实实验流程。
7. 脱离输入重建：记录文件在新会话打开，不加载原视图数据，仍能在放置的 Screen/Probe 上重建。
8. 机械与存储：扫描全行程无非法干涉，光束受显式不透明代理遮挡；旧项目迁移、撤销和恢复保持光学几何与记录状态含义。

每个物理模型先有确定性 CPU 参考与独立基准，再做 GPU 对照。大视场、复杂体材料或未校准域应显示“不支持/实验性”，不能把低分辨率近轴预览包装成实物复现。

后续实现的第一项建议是 P1 的“单色打印头 + 简化工作台 + 机械/通光诊断”，并以 P2 的独立重建接口作为设计约束。不要先继续扩充通用数字孪生器件清单。

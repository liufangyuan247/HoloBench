# waveprop external validation data

This directory contains validation-only reference fields generated by the
independent `waveprop` Python package. Nothing under this directory is linked
into, imported by, or distributed as a runtime dependency of HoloBench.

The four cases exercise different numerical paths:

- `asm_rectangular_tilted_gaussian`: exact angular-spectrum propagation on a
  rectangular grid, with waveprop padding and band limiting disabled to match
  HoloBench's documented periodic-boundary reference convention. The public
  `angular_spectrum` entry point is used because waveprop 0.0.12's sibling
  `angular_spectrum_np` has an upstream `Ny`/`Nx` initialization defect when
  `pad=False`.
- `fresnel_tf_square_gaussian`: waveprop's same-sampling Fresnel convolution
  on a square grid. The distance is exactly 20,000 vacuum wavelengths, so the
  longitudinal carrier omitted by `waveprop.fresnel_conv` is unity and no
  post-hoc phase correction is applied.
- `fraunhofer_rectangular_double_slit`: waveprop's Fraunhofer diffraction
  integral for a sampled double slit on a rectangular grid.
- `slm_selected_pixel_fraunhofer`: waveprop's physical SLM cell rasterizer
  (pitch, active cell and dead space) followed by its Fraunhofer integral for a
  selected pixel. HoloBench commands run from negative to positive Y/X, whereas
  waveprop indexes device values from its positive-Y/positive-X corner, so the
  generator flips both command axes. waveprop 0.0.12 also rasterizes X cells one
  field sample to the right; metadata records the corresponding explicit +1 um
  HoloBench device-centre offset. Neither reference field is shifted after
  generation.

Every CSV stores both the exact input samples passed to waveprop and the
resulting complex output samples. This avoids reconstructing the input with a
second implementation in C++ and makes the external provenance auditable.
Coordinates and samples are row-major (`y`, then `x`) and written with 17
significant decimal digits. Metadata records SI sampling, phasor convention,
FFT choices, and package versions. `SHA256SUMS.json` binds the generator,
requirements, metadata, and data files.

Generate or refresh the files from the repository root:

```powershell
py -m pip install -r validation/waveprop/requirements-validation.txt
py validation/waveprop/generate_goldens.py
py validation/waveprop/generate_goldens.py --verify
```

The generated fields use waveprop 0.0.12's `exp(+i k z)` spatial propagation
convention. HoloBench's locked convention is documented in ADR 0005. Any
future package or parameter change must regenerate the data and update the
manifest in the same commit.

## Locked comparison gates

The C++ tests compare the complete complex field using normalized L2 error and
maximum absolute error divided by the reference peak. They independently
compare intensity with the same two metrics. The initial Windows double-
precision reference measurements were:

| Case | Complex L2 | Complex max/peak | Intensity L2 | Intensity max/peak | Gate |
|---|---:|---:|---:|---:|---:|
| ASM rectangular Gaussian | 6.37e-12 | 2.33e-12 | 2.64e-12 | 1.90e-12 | complex 5e-11; intensity 1e-10 |
| Fresnel TF Gaussian | 1.84e-11 | 1.73e-11 | 1.01e-12 | 6.41e-13 | complex 5e-11; intensity 1e-10 |
| Fraunhofer double slit | 1.65e-9 | 2.04e-9 | 6.24e-16 | 8.26e-16 | complex 5e-9; intensity 1e-10 |

The Fraunhofer complex discrepancy is a nearly pure phase effect from the two
implementations' different double-precision range reduction of the 1 metre
longitudinal carrier (`k*z` is approximately 9.9e6 radians). Its intensity
agreement remains at machine precision, so the separate intensity gate guards
against using carrier-phase tolerance to hide an amplitude or normalization
error.

The SLM case compares the complete sampled amplitude mask exactly, including
dead space, then compares complete back-focal intensity and coordinates. Its
complex output phase is not a shared observable: waveprop's free-space
Fraunhofer expression includes a quadratic output phase, while HoloBench's
front-to-back focal-plane ABCD transform does not. The locked intensity L2 and
maximum/peak gates are both `1e-12`.
